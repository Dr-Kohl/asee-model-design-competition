# ASEE Model Design Competition Resources

Static GitHub Pages site for current competition materials and a permanent year-by-year archive. It is intentionally content-neutral until faculty approve a rules release.

## Publish safely

1. Keep this repository private while rules are under review.
2. Create `years/YYYY/` for the approved competition year and add its permanent `index.html` page.
3. Put approved public files in `downloads/YYYY/`; preserve the source CAD separately if it should not be public.
4. Add dated public answers to `clarifications/YYYY.md`, including affected rule sections and document versions.
5. Update the home page's review notice, current-year link, organizer email, and release version/date.
6. Make the repository public, enable GitHub Pages from the `main` branch, and test every download from a private browser window.

## Suggested shared stewardship

Make the four faculty members GitHub organization owners when a dedicated competition organization is established. One or two maintainers can handle routine site updates; release decisions remain faculty-approved.

## Large files

Individual STL files work well in the repository. Consider GitHub Releases for larger CAD packages or ZIP bundles, and link their versioned release assets from the yearly page.
